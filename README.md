# The Soul App Backend

A Spring Boot backend application for The Soul App, providing therapy and mental health services.

## 🚀 Features

- User Authentication & Authorization
- Therapist-Patient Matching
- Assessment Management
- Session Scheduling
- Payment Processing
- Blog & Content Management
- Avatar & Gamification System
- Notification System

## 🛠 Tech Stack

- !! Most of the development was made with the aid of AI !!
- Cursor IDE
- Java 21
- Spring Boot 3.x
- Spring Security
- AWS Services:
  - Cognito (Authentication)
  - S3 (File Storage)
  - SES (Email Service)
  - SNS (SMS Notifications)
  - DynamoDB (NoSQL Database)
  - CloudWatch (Monitoring)
  - Beanstalk (Compute)
- Postgresql (RDS)
- JWT Authentication
- Gradle Build System

## 📋 Prerequisites

- Java 21
- Gradle
- AWS Account
- MySQL Database

## 🔐 Security

- JWT-based authentication
- Role-based access control
- Rate limiting
- CORS configuration
- SSL/TLS encryption
- Input validation
- SQL injection prevention

## 📈 Monitoring

- AWS CloudWatch integration
- Health endpoints
- Metrics collection
- Log aggregation
